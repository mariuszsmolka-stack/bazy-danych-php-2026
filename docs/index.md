# Bazy danych i PHP - aplikacje WWW w XAMPP

Znasz podstawy Pythona? W tym kursie poznasz składnię PHP i nauczysz się odczytywać dane z MariaDB. Pracujemy lokalnie w XAMPP, z phpMyAdmin i Visual Studio Code.

## Spis treści

1. [Baza Islandia - import, tabele i relacje]({{ '/00-organizacja/01-baza-islandia.html' | relative_url }}) - przygotowanie danych do lekcji 2.
2. [Lekcja 1 - podstawy PHP i pierwsze tablice]({{ '/01-podstawy-php/01-podstawy-php.html' | relative_url }}) - uruchamianie skryptów, zmienne, pętle i tablice.
3. [Lekcja 2 - PHP i odczytywanie danych z bazy Islandia]({{ '/02-php-i-mariadb/01-odczyt-danych.html' | relative_url }}) - połączenie, `SELECT` i pobieranie rekordów przez `mysqli`.

## Jak pracować?

Czytaj wyjaśnienia, uruchamiaj przykłady i wykonuj ćwiczenia po kolei. Lekcja 1 nie wymaga połączenia z bazą. Przed lekcją 2 przygotuj bazę `Islandia` według instrukcji importu.

GitHub Pages prezentuje materiały. Kod PHP działa lokalnie w XAMPP; ta strona nie wykonuje skryptów PHP ani zapytań do Twojej bazy.

## Odniesienie do egzaminu

Kurs przygotowuje do INF.03. Materiałem odniesienia jest arkusz CKE **INF.03-01-26.06-SG**, egzamin praktyczny z czerwca 2026, dotyczący portalu turystycznego. Stosujemy proceduralne funkcje `mysqli`. Pełny arkusz PDF nie jest częścią publikacji.
