## Jak pracować?

Czytaj wyjaśnienia, uruchamiaj przykłady i wykonuj ćwiczenia po kolei. Lekcja 1 nie wymaga połączenia z bazą. Przed lekcją 2 przygotuj bazę `Islandia` według instrukcji importu.

GitHub Pages prezentuje materiały. Kod PHP działa lokalnie w XAMPP; ta strona nie wykonuje skryptów PHP ani zapytań do Twojej bazy.

## Odniesienie do egzaminu

Kurs przygotowuje do INF.03. Materiałem odniesienia jest arkusz CKE **INF.03-01-26.06-SG**, egzamin praktyczny z czerwca 2026, dotyczący portalu turystycznego. Stosujemy proceduralne funkcje `mysqli`. Pełny arkusz PDF nie jest częścią publikacji.
